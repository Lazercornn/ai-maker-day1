
# Smart CLI Assistant

Консольный AI-помощник на Python для анализа резюме, вакансий и коммерческих предложений с использованием Google Gemini API.

## Возможности

- Анализ резюме, вакансий и коммерческих предложений.
- Получение рекомендаций с помощью AI.
- Ввод многострочного текста.
- Вывод результата в форматированной таблице.
- Обработка ошибок API и проверка пустого ответа.
- Консольный интерфейс на базе Rich.

## Технологии

- Python 3.10+
- Google Gemini API
- Google Gen AI SDK
- python-dotenv
- Rich
- Git и GitHub

## Установка

Клонируйте репозиторий и перейдите в его папку:

```bash
git clone https://github.com/Lazercornn/ai-maker-day1.git
cd ai-maker-day1
```

Создайте виртуальное окружение:

```bash
python -m venv .venv
```

Активируйте его в Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

Установите зависимости:

```bash
python -m pip install google-genai python-dotenv rich
```

## Настройка API

1. Создайте файл `.env` в корне проекта.
2. Добавьте в него переменную:

```text
GEMINI_API_KEY=ваш_api_ключ
```

3. Укажите действительный API-ключ Google Gemini.

Не публикуйте API-ключ и не добавляйте файл `.env` в Git.

## Запуск

```bash
python smart_cli_assistant.py
```

Выберите тип анализа:

- `резюме`
- `вакансию`
- `предложение`

Вставьте текст для анализа. Для завершения многострочного ввода напишите `END` на отдельной строке.

После обработки Gemini программа выведет результат в терминале.

## Структура проекта

- `smart_cli_assistant.py` — основной AI-помощник.
- `ai_assistant.py` — отдельная версия консольного AI-чата.
- `main.py` — начальная точка проекта.
- `test_gemini.py` — проверка подключения к Gemini API.
- `.gitignore` — исключения для Git.

## Проверка кода

Проверка синтаксиса:

```bash
python -m py_compile smart_cli_assistant.py
```

Проверка качества кода:

```bash
ruff check smart_cli_assistant.py
```

## Ограничения

- Для анализа требуется доступ к Gemini API и действительный API-ключ.
- Доступность модели и условия использования API могут меняться.
- Программа пока работает в консоли и не имеет графического интерфейса.
